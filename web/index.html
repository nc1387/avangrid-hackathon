Backup reserve

Defaults: Enphase IQ Battery 10C ×2 from the Challenge Statement (20.16 kWh, 7.68 kW, 89.4%). Charging is capped at 3 kW: a 200-amp service should not take more than ~3 kVA of added load. The 11.52 kW 10-second rating isn't modelled (hourly data).

Charging windows
System peak cut target

Each segment gets a mix of windows that maximizes total savings while keeping these customers' combined peak at least this far below today's. If that isn't achievable, the lowest achievable peak is used.

Each battery spreads its recharge evenly over the rest of its window. If every battery uses the same window they all charge together, which can set a new system peak.
